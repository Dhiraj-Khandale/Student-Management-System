# Student Management System

A console-based Student Management System built using Python and SQLite database.

## 🛠️ Technologies Used
- Python
- SQLite (built-in with Python)
- OOPs Concepts (Class, Object, Encapsulation)

## 📋 Features
- ➕ Add new student records
- 📋 View all students
- 🔍 Search student by name
- ✏️ Update student marks
- ❌ Delete student record
- 💾 Data stored permanently in SQLite database

## 📁 Project Structure
StudentManagementSystem/
├── main.py        # Main Python file
└── students.db    # SQLite database (auto created)

## ▶️ How to Run

Make sure Python is installed on your system.

git clone https://github.com/Dhiraj-Khandale/Student-Management-System.git
cd Student-Management-System
python main.py

## 💡 Concepts Used
- Object Oriented Programming (OOPs)
- SQLite Database Connection
- CRUD Operations (Create, Read, Update, Delete)
- Menu Driven Program
